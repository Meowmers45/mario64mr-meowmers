# Your own characters

Put character packs here (a folder each, or a `.zip` of one) and run the installer again: each one becomes a choice
in the game's options (pause, then R: Character). What a pack has in it: see "Your own characters" in the main
README.

`_example/Halo Mario` is a small example pack to copy from: a halo over Mario's own body, with its own texture and
its own jump clip. Folders starting with `_` are left out, so it's only made into the game if you copy it out of
`_example` (or give it with `--character`).
